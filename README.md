# Replication package for: Mapping the structural gap between IT leadership and IT management in SMEs: A comparative and longitudinal bibliometric analysis

This repository contains the replication package for the study **“Mapping the structural gap between IT leadership and IT management in SMEs: A comparative and longitudinal bibliometric analysis.”**

It was created to support transparency, computational reproducibility, and reuse of the research workflow.

## Contents

The repository includes:

- validation and filtering scripts used to check and clean the exported records
- temporal filtering logs
- cleaned corpora used in the bibliometric analysis
- thesaurus files applied in VOSviewer
- processed bibliometric tables and intermediate outputs used to validate the methodology section
- documentation describing the analytical workflow

## Repository structure

A typical structure of this repository is:

- `scripts/` — validation, filtering, and inspection scripts
- `data/interim/` — cleaned corpora used in the analysis
- `data/processed/` — processed bibliometric outputs and tables
- `data/docs/` — logs and validation notes
- `data/thesaurus/` — thesaurus files used in keyword normalization

Please note that the original raw CSV exports from Scopus are **not** publicly redistributed in this repository.

## Scope of the public deposit

The public version of this repository was prepared to allow readers to reproduce the main analytical steps reported in the manuscript without redistributing licensed raw exports.

Accordingly, the repository provides the cleaned and documented analytical objects required to understand, inspect, and reproduce the reported methodological decisions.

## Reproducibility

The repository supports reproduction of the methodological workflow reported in the manuscript, including:

- validation of exported records
- temporal filtering of corpora
- inspection of keyword inventories
- verification of metadata completeness
- cross-checking of processed bibliometric tables used in the manuscript
